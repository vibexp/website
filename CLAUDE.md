# CLAUDE.md

Guidance for Claude Code working in this repository.

## What this is

The marketing website for **VibeXP**, an open-source, self-hostable AI knowledge
base. This is a **public** repository: never commit secrets, real API keys, DSNs,
or tokens. There is no hosted/paid product — the site is open-source-only;
primary CTAs point at the GitHub repo (`https://github.com/vibexp/vibexp`), not a
hosted app.

Statically-generated **Astro** site. Page content is React components rendered as
Astro islands. Design tokens come from the public npm package
`@vibexp/design-system` (imported as CSS in `src/styles/index.css`).

## Commands

```bash
npm ci
npm run dev         # astro dev → :4321
npm run build       # astro build → static dist/
npm run lint        # eslint
npm run type-check  # astro check
npm run test        # jest
```

Run `lint`, `type-check`, and `test` before committing — CI (`.github/workflows/ci.yml`)
runs all three plus the build.

## Layout

- **Routing:** `astro-src/pages/*.astro` (Astro `srcDir` is `astro-src`). Each
  route imports a React page from `src/pages/*.tsx` and renders it as an island
  in `astro-src/layouts/BaseLayout.astro`. **Removing a page = delete BOTH the
  `.astro` route and its `.tsx` component** (and any `*.illustrations.css`).
- **Pages:** Home, How it works, the `/features` hub, and feature detail pages
  (prompts, blueprints, memory, artifacts, mcp-integration).
- `src/components/{layout,sections,ui}`, `src/hooks`, `src/utils` (`seo.ts`,
  `gtm.ts`), `src/lib/utils.ts`. `react-router-dom` is aliased to
  `src/lib/astro-router-shim.tsx`.
- **SEO:** per-page metadata in `src/utils/seo.ts` + `astro-src/components/SEO.astro`.
- **Sitemap:** auto-generated by `@astrojs/sitemap` from built pages — do not
  hand-edit it; deleting a page removes it automatically.

## Deployment (GitHub Pages)

Published to GitHub Pages on **vibexp.io** (`public/CNAME`), `output: 'static'`,
Astro emits its own `404.html`. `publish.yml` builds and deploys on push to `main`;
`ci.yml` checks PRs. No auth token needed (design-system is public npm).

## Conventions

- TypeScript, no `any`. Prettier (no semicolons, single quotes — `.prettierrc`).
- Tailwind utility classes; use design-system tokens (`bg-background`, etc.), not
  raw colors. Path alias `@/` → `src/`.
- Sentry is opt-in via env; the OSS build runs without it.
